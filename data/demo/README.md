# Demo Data Samples

This directory contains sample data files for demonstrating ZiggyAI functionality.

## Files

### `sample_portfolio.json`
A complete demo portfolio showing:
- 8 positions in major tech stocks
- Cash balance and total value
- Unrealized P&L for each position
- Portfolio performance metrics

### `sample_signals.json`
Trading signals demonstrating the AI analysis:
- BUY/HOLD/SELL recommendations
- Confidence scores and reasoning
- Technical indicators (RSI, MACD, SMA)
- Market conditions summary

### `sample_trades.json`
Historical trade data showing:
- Trade execution details
- P&L calculations
- Win/loss statistics
- Strategy attribution

## Usage

These files can be used for:
1. **Frontend Development**: Testing UI components with realistic data
2. **API Testing**: Mock responses for development
3. **Documentation**: Examples in API docs
4. **Demos**: Showcasing platform capabilities

## Data Generation

In production, this data would be generated by:
- Real-time market data providers
- ML signal generation pipeline
- Paper trading engine
- Portfolio management system

## Note

This is **demonstration data only**. It does not represent:
- Real trading recommendations
- Actual market conditions
- Live portfolio positions

Always use proper research and risk management for real trading decisions.
